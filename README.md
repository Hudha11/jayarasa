# Website Company Profile Jaya Rasa

Website company profile satu halaman menggunakan React + Vite dengan struktur komponen terpisah.

## Menjalankan project

```bash
npm install
npm run dev
```

## Build dan preview production

```bash
npm run build
npm run preview
```

## Struktur folder


## Konten yang diambil dari company profile

- Jaya Rasa berdiri pada 1998.
- Telur Asin Pindang dikembangkan pada 2000.
- Crispy Baby Crabs tercatat sebagai produk best seller.
- Produk lainnya: Sambal Kepiting, Sambal Ikan Roa, Sari Buah Nanas, dan Keripik Tempe Kepiting.
- Kontak dan alamat mengikuti company profile yang diberikan.
